# Independent Application Review & Strict Scoring

Use for reviews of resumes, CVs, cover letters, statements of purpose, research/visiting applications and for the final independent pass of an end-to-end application. **Do not turn review-only requests into automatic drafting.**

## Inputs and order

Read the actual artifact; target JD/program prompt, expected audience, role/Req ID and submission requirements; the **original user- or institution-supplied rubric if available**; and verifiable applicant evidence. Missing official rubric means score weights or cutoffs are unknown, **not** an invitation to invent an official grade.

## Required evaluation sequence

### 1. Hard failure / submission compliance

Check actual eligibility (year/degree, geographic and work arrangement where pertinent), wrong company/lab/program/role/Req ID, missing required attachment, target constraints and mandatory form, word/page/file limits, dates, deadlines, factual contradictions, fabricated claims, unsupported publication/deployment status, errors in recipient/format, and spelling/grammar mistakes that matter. State **Pass / Fail / Unverified**, with grounds. A fatal eligibility mismatch cannot be compensated with beautiful prose.

### 2. Priority criteria coverage

Extract the 3–5 most consequential requirements. Map each to an actual example and identify what is covered, weak, unsupported or unaddressed. Detect forced relevance, irrelevant achievement dumping, unfamiliar jargon and tools listed with no contribution or value.

### 3. Evidence audit

For each material achievement, award, job, education credential, result, publication, user count or quantified claim classify:
- **Supported**: primary/applicant-confirmed evidence is available and fits the exact claim.
- **Unsupported**: no credible corroborating source or contradicts known status.
- **Unclear / not verified**: incomplete source, conflicting evidence or a time-sensitive fact that needs a fresh check.

Never mark information verified merely because it was in an earlier AI-authored draft. Never revise an uncertain claim into a stronger unsupported one.

### 4. Six-dimension evaluation

Apply the **actual original rubric and its official weights** when available. Otherwise use these six **qualitative dimensions**, without pretending official numbers exist:

| Dimension | What to assess |
| --- | --- |
| Clarity | Immediate purpose, logical structure and unambiguous claims |
| Conciseness | Information density, duplication, appropriate length |
| Design | Legibility, scannability and compliant document format |
| Audience | Appropriate hiring/admissions reader, accessible terminology, tailored tone |
| Accuracy | Correct, attributable facts, consistent dates/names, grammar |
| Content | Role/program relevance, strong personal evidence and persuasive substance |

Give scores only when a scale genuinely exists, explain evidence and deductions for each criterion, and avoid inflated 90–100 scores or subjective praise without justification. Keep the same rubric for draft versus revision comparisons.

### 5. Independent skepticism and prioritized fixes

Review the output **as if you were not its author**. The model's earlier draft is not an achievement or quality guarantee. Identify the **three highest-impact** problems first, then at most 3–5 actionable fixes. Provide exact replacement wording only where this helps and never manufacture missing facts.

### 6. Revision and blind second pass

Revise only if the user requested revision or end-to-end delivery. Preserve good text and valid claims; fix the most local passages necessary. Reevaluate with the **same** rubric; report whether defects were corrected and what is still unverified. Do not change scales or inflate results to make the revision appear better.

## Document-specific pitfalls

- **Cover letter**: real role, exact identifier if known, source if verified, appropriate school/major/degree statement, truthful value proposition, 1–3 high-relevance experiences, usually 200–250 words and no more than 300 unless required otherwise; three or four paragraphs; natural first-person HR voice; no automatic AI disclosure.
- **Resume**: default one page for current students; clear personal contribution and output instead of duty description, quick screening relevance, accurate verbs and dates, ATS-friendly structure, metrics with sources, no pile of tools.
- **Academic CV**: credible research/teaching/publication status; no invented academic authorship or empty padding.
- **SOP / program statement**: comply with *that* program's precise prompt, word/section requirements and selection criteria; coherent motivation and evidence-based preparation, without repurposing the cover-letter format.
- **Research/technical content**: correct attribution, responsible citation, nonmisleading figures/axes, context-sensitive tense/voice, and no arbitrary contiguous-word rule for plagiarism.
- **Other conditions**: truthful location/work availability, language proficiency, educational status, methodology, numerical results and qualifications only if needed and checked; no automatic commitments.

## Review-only output contract

1. **Verdict** — Pass / Fail / Unverified for mandatory requirements, with reason.
2. **Rubric** — source of criteria, criterion-by-criterion evidence and deduction; numerical score *only* if defined.
3. **Top fixes** — 3–5 or fewer, prioritized by expected impact, with directly replaceable suggestions where possible.
4. **Verified revision** — only if asked, whole document or local edits as requested, plus an explicit fact-check list.

Be concise, objective and specific. Avoid flattery. If required information is missing, state the exact limitation rather than assigning unjustified numerical scores.

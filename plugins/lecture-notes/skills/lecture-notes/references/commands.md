# Quick Commands

These are convenience phrases, not rigid syntax.

- `生成课堂笔记` — slides/transcript → complete Notion Master Note by default
- `解释这里` — explain in chat, do not edit note
- `处理评论` — read questions/comments attached to selected Notion text and answer them in chat
- `写进笔记` — compress the latest useful explanation and merge it into the correct Notion location
- `重写这里` — replace the targeted passage with a clearer version
- `检查完整性` — compare note against current lecture sources and repair omissions in the same Master Note
- `整理这节课` — remove redundancy and normalize structure without losing knowledge
- `只是帮我理解，不要写进去` — keep the explanation only in chat
- `导出到 Google Docs` — create/update a Google Docs copy when explicitly requested

The user may use natural-language variants. Follow intent, not exact wording.

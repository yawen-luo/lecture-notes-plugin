# Quick Commands

These are convenience phrases, not rigid syntax. Every persistent note action uses the same canonical Notion Master Note for the lecture.

- `生成课堂笔记` — slides/transcript → locate or create the lecture's Notion Master Note, write the complete note, verify it, and return the page link.
- `解释这里` — explain the selected/current passage in chat only; do not change the Notion note unless the user asks to write it in.
- `处理评论` — read unresolved inline comments on the current Notion Master Note, answer each clear study question, integrate durable explanations into the relevant body section, reply in the original discussion thread, verify the edit, and return the same page link.
- `重写这里` — rewrite the targeted Notion passage for clarity while preserving knowledge content and course terminology.
- `检查完整性` — compare the current Notion Master Note with the current lecture slides/transcript, repair omissions or over-included untaught material in place, verify, and return the same page link.
- `整理这节课` — improve the same Notion page's structure, hierarchy, readability, and accidental duplication without changing the lecture coverage boundary.

The user may use natural-language variants. Follow intent, not exact wording.

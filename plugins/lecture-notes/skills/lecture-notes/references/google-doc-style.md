# Google Docs Style

Load this reference when creating or reformatting the lecture Master Note.

## Principle

Preserve content. Formatting should improve reading without turning the note into an AI-generated dashboard.

## Default visual style

- Body text: about 12.5 pt.
- Comfortable line spacing: around 1.3–1.4.
- Clear H1/H2 hierarchy with generous spacing.
- Use normal paragraphs as the default.
- Do not convert ordinary prose into bullets.
- Use bold sparingly.
- Avoid decorative emoji and excessive callouts.
- Keep formulas, flows, and compact mappings visually separated when that improves scanning.

## Highlight blocks

Use only a small number of subtle highlight blocks, typically for text that already functions as:
- “记忆”
- “可以记成”
- “核心原则”
- a compact core mental model

Recommended appearance:
- very light blue-gray or gray background;
- a thin left border;
- modest indentation/padding;
- no bright colors.

Do not turn every definition or example into a block.

## Existing-note formatting rule

If the user says the existing content is already good and only asks for formatting:
- do not rewrite;
- do not add new bullet points;
- do not add extra bolding;
- change only typography, spacing, hierarchy, and a few justified blocks.
